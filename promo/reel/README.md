# PATIENT ZERO — 20초 쇼릴

영상 편집기 없이 **코드만으로** 만든 1920×1080 · 60fps · 20초 모션그래픽.
그림은 전부 게임이 이미 가진 것(원화 · 스크린샷 · 로고 · 아이콘)만 쓴다 — 따로 그리면 거짓말이 된다.

```
promo/reel/
  comp.html   REEL.seek(t) 가 매 프레임을 처음부터 그린다 (DOM + CSS 3D + 캔버스 둘)
  render.js   헤드리스 크롬 네 대로 나눠 찍고, ffmpeg 로 굽는다
  music.js    사운드트랙을 코드로 합성한다 (의존성 없음)
```

## 만드는 법

```bash
export REEL_OUT=<스크래치 폴더>            # 프레임 1200장을 저장소에 남기지 않는다
node promo/reel/music.js                   # → $REEL_OUT/music.wav
node promo/reel/render.js --frames --workers 4
FFMPEG=<ffmpeg 경로> node promo/reel/render.js --encode
#  → promo/patient-zero-showreel.mp4        (crf 17, 마스터)
#  → promo/patient-zero-showreel-web.mp4    (crf 23, 12Mbps 상한)
FFMPEG=<ffmpeg 경로> node promo/reel/render.js --vertical
#  → promo/patient-zero-showreel-vertical.mp4      (1080×1920)
#  → promo/patient-zero-showreel-vertical-web.mp4
```

**세로판(쇼츠·릴스)** 은 다시 찍지 않는다 — 다 구운 가로판을 폭에 맞춰 가운데 놓고,
위아래 656px 는 같은 화면을 **늘여서** 흐리게 깐다(몇 초면 끝난다).
가운데만 잘라 키우면 한쪽에만 밝은 덩어리가 생겨 화면이 기운다 — 늘인 판은
위아래가 가운데 그림과 이어져 이음매가 안 보인다. 비네트로 귀퉁이를 눌러 눈을 가운데로 모으고,
가는 선 두 줄로 가운데 판을 세운다. 가운데 그림은 y 656–1264 라 쇼츠·릴스의 UI 안전 영역 안에 든다.

몇 장만 보고 싶으면 `--preview 4.35,9.4,13.2` → `$REEL_OUT/preview/`.
브라우저에서 `comp.html` 을 열고 **스페이스**를 누르면 그 자리에서 돌아간다(`?t=6.2` 로 한 장면만 볼 수도 있다).

한국어판은 `--lang ko`(그리고 `comp.html?lang=ko`) — 글과 로고가 바뀐다. 파일 이름에 `-ko` 가 붙는다.
기본은 **영어**다.

## 뼈대

시간은 오직 `t` 에서 온다. **CSS 애니메이션·트랜지션은 한 줄도 쓰지 않는다** —
그래야 크롬 네 대가 프레임을 나눠 찍어도 똑같은 그림이 나온다.

층은 셋: `#bg` 캔버스 → `#dom`(CSS 3D 가 맞는 두 장면) → `#fx` 캔버스(덮는 효과·그레인·레터박스).
**장면 위에 얹는 것은 반드시 위쪽 fx 캔버스에** — 아래 bg 는 풀블리드 그림에 가린다.

| 8.0–10.0 | **ROSTER** | 얼굴 20장이 3D 벽으로 내려앉고 제로가 앞으로 |

| 12.0–14.0 | **CAMPAIGN** | 포스터 19장이 모션블러로 지나가 한 장에 선다 |

## 직접 만든 것들

- **전염 모형** — 격자 위 13,072명에 최소 힙으로 전파 사건을 돌려 한 번만 계산해 둔다.
  점마다 '누구에게서 언제' 옮았는지를 들고 있어서 **전파 나무**(선)를 그릴 수 있고,
  화면의 숫자도 지어낸 값이 아니라 그 표에서 센다. S2·S3·S10 이 같은 표를 쓴다 —
  글자가 되는 가루도, 마지막에 로고로 빨려드는 점도 같은 사람들이다.
- **모션블러** — 포스터 띠는 한 프레임 안에서 위치를 16번 겹쳐 찍는다(180° 셔터).
  속도는 손으로 미분하지 않고 **한 프레임 전과의 차**로 잰다.
- **색수차** — 충격 순간에만, bg 캔버스의 적·청 채널을 떼어 어긋나게 다시 합친다(진짜 채널 분리).
- **투영** — 기기를 가리키는 선은 CSS 3D 와 **똑같은 차례로 직접 투영**해서 찍는다.
  눈대중으로 잡으면 기기가 기울 때 HUD 에서 어긋난다.
- **사운드트랙** — D 단조, 120 BPM. 화면의 감염 곡선이 그대로 **빨라지는 맥박**이 된다.
  17.5 에 음악을 끊고 18.0 에 내리친다.

## 밟았던 것들

1. **장면 div 와 안쪽 판에 같은 id 를 주지 말 것.** `#dom > .scene` 쪽 특정도가 `#wall` 보다 높아서
   `left/top:50%` 가 통째로 무시되고, 벽이 화면 왼쪽 위 구석으로 밀렸다. 안쪽은 `#wallGrid`·`#deckRig` 로 뒀다.
2. **유행 곡선은 시간이 아니라 사람 수로 몰아야 한다.** 물결은 둥글게 퍼지는데 모서리 사람들이 제일 늦어서,
   시간으로 몰면 화면이 3초쯤에 이미 다 빨개진다. `timeAtFrac(분위)` 로 바꿨다.
3. **물결이 화면을 다 먹으면 볼 게 없다.** 3.86초부터 주제를 숫자로 옮긴다 — 벌판은 어두워지고
   세던 수가 가운데로 올라와 커진다. 그 수가 곧 다음 장면의 제목 자리에 선다.
4. **글자는 먼저 깔고 알갱이를 그 위에 얹는다.** 반대로 하면 '감염자들로 쓴 글자'가 아니라 그냥 글자로 보인다.
5. **매 프레임 난수 그레인은 H.264 를 터뜨린다.** 미리 구운 판 여덟을 돌려 쓰고 α 는 .055 로 둔다.
6. **만 삼천 개를 arc 로 그리면 못 쓴다.** 작은 점은 `fillRect`, 선 만 개는 `beginPath` 한 번에 모아 한 번 `stroke`.
7. **CDP 의 첫 captureScreenshot 은 첫 페인트보다 앞설 수 있다.** 버리는 한 장을 먼저 찍는다.
8. **로고는 그림 테두리가 아니라 글씨가 실제로 차지한 칸으로 앉힌다**(`alphaBox`).
   영어판 원화는 둘레 여백이 넓어서, 그림 기준으로 두면 한국어판과 자리가 달라진다.
9. 한 프레임을 통째로 열고 모션블러를 넣으면 그림이 녹는다 — **180° 셔터**(절반)로.

## 딸린 것

- 글꼴은 `fonts/`(Barlow Condensed · Gothic A1). 없으면 `node tools/fetch-fonts.mjs`.
- `shots/gameplay.png` 를 쓴다. 없으면 `node tools/store-shots.mjs` 로 다시 찍는다(그 한 장면만 비어서 나온다).
- ffmpeg 는 저장소에 두지 않는다 — `FFMPEG=` 로 넘긴다.
