## 영어판

영어로 띄워 다시 찍어 `-en` 폴더에 넣었다 — 번역 자막을 얹은 것이 아니라 **게임 화면 자체가 영어**다.

챕터 「더 많은 감염을, 더 높은 기록을.」)도 같은 방식으로 영어판을 구웠고(`tools/gen-art-en.mjs`),
게임이 언어에 따라 갈아 끼운다(`js/i18n.js` 의 `syncTitleLogo`). 그래서 영어 스크린샷에 한국어가 없다.

## 스크린샷 순서

번호 순서대로 올린다. 앞 두 장이 **실제 플레이 화면**이다 — 타이틀·로그인만 올리면 2.3.3 으로 잡힌다.

1. `01-outbreak` 90초 한 판 · 감염이 번진다
2. `02-dash` 돌진으로 인파를 뚫는다
3. `03-lobby` 로비 · 대표 감염자
4. `04-chapters` 챕터 선택
5. `05-characters` 캐릭터
6. `06-recruit` 한정 모집

## 어떻게 만들었나

- **스크린샷은 생성 그림이 아니다.** `tools/store-shots.mjs` 가 실제 게임을 터치 기기 뷰포트로 띄워,
  스냅샷을 보고 키보드로 사람을 쫓아 감염시킨 뒤 찍는다. 챕터 5 까지 깬 저장을 심어 빈 칸이 없게 했다.
  뷰포트를 크기/배율로 나눠 잡아 화소를 정확히 맞춘다(예: 932×430 @3 = 2796×1290).
- **홍보 그림은 생성 원본 한 장**(`assets/src/store-promo.png`, `tools/gen-promo.mjs`)에서 잘라 냈다.
  프롬프트는 [`../ART-DIRECTION.md`](../ART-DIRECTION.md) 에 있다. 그래픽 이미지에만 게임 로고를 얹었다.
- **아이콘**은 `tools/gen-icon.mjs`(원화) → `tools/bake-icon.mjs`(크기들). 알파는 눌러 없앴다 —
  애플은 투명이 있는 아이콘을 거부한다. maskable 한 장만 알파를 남긴다(안드로이드 적응형).
- 올리거나 게시하는 작업은 하지 않았다. 스토어의 최종 크롭은 각 콘솔 미리보기로 확인한다.

## 영상

20초 티저는 [`../promo/`](../promo/) 에 있다 — 1920×1080 · 30fps · H.264. 한국어판·영어판 둘.

**App Store 앱 미리보기는 1920×1080 을 안 받는다.** Dynamic Island 아이폰 칸이 받는 가로 크기는
1920×886 하나라, 같은 프레임에서 위아래를 잘라 따로 굽는다 —
`promo/patient-zero-preview-1920x886.mp4` · `-en.mp4`.

## 다시 굽기

```
node tools/store-shots.mjs            # 스크린샷 5묶음 (30장)
node tools/store-shots.mjs --lang en  # 영어판 5묶음 (30장)
node tools/gen-logo-en.mjs            # 영어 로고 (생성)
node tools/gen-promo.mjs              # 홍보 원본 한 장 (생성, --force 로 다시)
node tools/store-promo.mjs            # 홍보 그림 → 요구 화소들 (피처 그래픽은 한·영 둘)
node tools/store-check.mjs            # 전부 다시 재고 manifest.json
```
